# Data Model Ringkas

- `USERS`: admin/dosen/mahasiswa dan kredensial hash.
- `WEEKS`: 14 minggu LMS.
- `MATERIALS`: 28 materi; 2 per minggu.
- `ACTIVITIES`: registry universal untuk kuis, diskusi, tugas, proyek, refleksi, peer review, testing, presentasi.
- `DISCUSSIONS`, `POSTS`: forum.
- `COMMENTS`: komentar universal, terutama submission.
- `SUBMISSIONS`: versioned submissions.
- `GRADES`: gradebook universal.
- `QUIZZES`, `QUIZ_QUESTIONS`, `QUIZ_ATTEMPTS`: kuis auto-grade.
- `GROUPS`, `GROUP_MEMBERS`: kerja kelompok.
- `PROJECT_PLANS`: perencanaan 5 proyek dan workflow review.
- `ANNOUNCEMENTS`: pengumuman.
- `ACTIVITY_LOG`: audit aktivitas.
- `RUBRICS`, `RUBRIC_SCORES`: disediakan untuk pengembangan rubrik lebih lanjut.
